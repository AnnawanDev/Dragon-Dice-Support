# Dragon Dice — Support & Feedback

Thank you for using Dragon Dice! We want to ensure you have the best possible experience rolling your dice and tracking your characters. 

If you are encountering an issue, have a feature request, or need assistance, please use one of the methods below to get in touch.

---

## How to Get Help

### 1. Report an Issue or Feature Request
The fastest way to get support is to open an issue directly on our project tracker. This allows you to see if other users are experiencing the same issue and track the progress of a fix.

*   [**Open a Support Ticket / Bug Report**](https://github.com/AnnawanDev/Dragon-Dice-Support/issues)

*Note: You will need a free GitHub account to open an issue here.*

## Frequently Asked Questions (FAQ)

**Q: Will there be more themed dice styles added in the future?**  
**A:** Yes! We are working on new character-themed animations. Feel free to submit a feature request via the links above if there is a specific style you want to see.

**Q: How do I change my Tavern Hero?**  
**A:** Go to **Settings → Tavern Hero** and choose the Barbarian, the Elf Ranger, or the Wizard. Your pick sits across the table from you while you roll.

**Q: What do tips get me?**  
**A:** Tips are optional and don't unlock any features. They're simply a thank-you that helps support future updates. You can leave one from **Settings**.

**Q: I tipped by mistake. Can I get a refund?**  
**A:** Tips are processed by Apple, so we can't issue refunds ourselves. You can request one from Apple at [reportaproblem.apple.com](https://reportaproblem.apple.com).

**Q: What usage data does Dragon Dice collect?**  
**A:** Dragon Dice collects anonymous usage stats, such as which dice get rolled most, so future updates focus on what matters at your table. There are no accounts, no personal info, and no tracking across apps. Usage stats can't currently be turned off in the app. See our [Privacy Policy](./Privacy) for full details.

**Q: The ROLL button is cut off on my small-screen iPhone.**  
**A:** Version 1.3 improved the layout on smaller screens like the iPhone SE. Please update to the latest version from the App Store. If you still have trouble, [open an issue](https://github.com/AnnawanDev/Dragon-Dice-Support/issues) and include your iPhone model and iOS version.
